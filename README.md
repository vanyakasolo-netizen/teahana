# Голоса NPC — D&D (Android, автономная версия)

Android-проект-обёртка для исходного `голоса-npc.html`. Веб-интерфейс и DSP-обработка включены в APK как локальные assets.

## Что включено
- Локальная обработка голоса: pitch, formant/тембр, глубина, яркость, хрип/шёпот, рычание, эхо, шумоподавление и громкость — в пределах возможностей исходного HTML.
- Живой режим через `AudioWorklet` и режим фраз.
- Локальное хранение библиотеки и настроек через WebView DOM Storage / IndexedDB.
- Импорт резервных копий и экспорт через системный выбор файлов Android.
- Доступ к микрофону только после системного разрешения Android.
- Сетевой клиент нейросетевого преобразования отключён; разрешения INTERNET в манифесте нет.

## Сборка APK

Требуется Android Studio с Android SDK Platform 35 и JDK 17. Откройте эту папку как проект Android Studio, дождитесь Gradle Sync, затем выберите **Build → Build Bundle(s) / APK(s) → Build APK(s)**.

Готовый debug APK после сборки появится в `app/build/outputs/apk/debug/app-debug.apk`.

## Важные замечания
- Это исходный Android-проект, а не уже собранный и подписанный APK. В текущей среде нет Android SDK и Gradle, поэтому бинарный APK здесь не был собран и не тестировался на устройстве.
- Для AudioWorklet нужен актуальный Android System WebView. Обновите Android System WebView через системный магазин обновлений, если живой режим не запускается.
- Android всё равно покажет запрос разрешения на микрофон. Без согласия пользователя микрофон не используется.
- В автономной версии нет нейросетевого RVC/серверного преобразования и нет сетевых запросов.

## Сборка через GitHub с телефона

В проект добавлен workflow `.github/workflows/android.yml`. Загрузите содержимое проекта в GitHub-репозиторий с веткой `main`. После загрузки откройте вкладку **Actions**, выберите **Build Android APK** и нажмите **Run workflow** (если сборка не стартовала автоматически после push). По завершении откройте запуск workflow, найдите раздел **Artifacts** и скачайте `GolosaNPC-debug-APK`. Внутри будет `app-debug.apk`.

Workflow собирает debug APK в облаке GitHub Actions. Для этого не требуется устанавливать Android Studio на телефон. APK не является релизной подписанной сборкой для публикации в Google Play.
